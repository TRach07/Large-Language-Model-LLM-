# Large Language Model (LLM) - Learning Repository

A comprehensive collection of projects and notebooks exploring Large Language Models, NLP techniques, and transformer architectures.

### 2. **Self-Attention Mechanism Implementation**
Step-by-step implementation of the self-attention mechanism used in Transformer models.

### 3. **Small Language Model (SLM) Design**

- 🔍 See README for details
